# 羽球物語

直向的手機羽球遊戲（網頁 PWA）：用手指滑動打出高遠、殺球、放網、撲球，還有花式打法。加到主畫面就能全螢幕、離線玩。

- 版本：1.11.0
- 程式：Three.js 0.160、@pixiv/three-vrm 3.4.5（從 jsDelivr 載入）
